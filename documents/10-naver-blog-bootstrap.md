# 네이버 블로그 부트스트랩 가이드

> **목적**: 네이버 블로그에 쿠팡 파트너스 상품 추천글 3~5개 수동 작성 → 승인 → 자동화 시스템 연동

---

## 1. 사전 준비

### 1.1 네이버 블로그 개설/준비
- 네이버 아이디로 블로그 개설 (`blog.naver.com/내아이디`)
- 블로그명, 카테고리 설정 (예: "생활용품 리뷰", "가전제품 추천")
- 프로필 사진, 소개글 작성 (신뢰도 확보용)

### 1.2 쿠팡 파트너스 가입
1. https://partners.coupang.com 가입
2. 본인 인증, 계좌 정보 등록
3. **승인 대기 상태** (글 작성 전에도 가입 가능)

### 1.3 추천할 상품 3~5개 선정
| 상품군 | 추천 예시 | 이유 |
|--------|-----------|------|
| 소형가전 | 무선청소기, 로봇청소기, 에어프라이어 | 검색량 높음, 단가 적당 |
| 주방용품 | 전기밥솥, 멀티쿠커, 진공포장기 | 교체 주기 짧음 |
| 생활용품 | 공기청정기, 가습기, 제습기 | 계절성 수요 명확 |
| 뷰티/건강 | 마사지기, 체중계, 구강세정기 | 재구매율 높음 |

**선정 기준**:
- 쿠팡에서 판매량/리뷰 많은 상품 (로켓배송 우선)
- 단가 3만~15만 원대 (수수료 3% 기준 건당 1,000~4,500원)
- 본인이 실제로 알거나 관심 있는 카테고리

## 2. 네이버 블로그 글 작성 가이드

### 2.1 글 구조 템플릿

```
제목: [제품명] 솔직 리뷰 - 장단점 총정리 (내돈내산)

본문 구조:
1. 도입 (왜 샀는가, 고민 포인트)
2. 제품 기본 정보 (가격, 스펙, 배송)
3. 사용 후기 - 장점 (3~5개)
4. 사용 후기 - 단점 (2~3개, 솔직하게)
5. 총평 & 추천 대상
6. 구매 링크 (쿠팡 파트너스 링크)
```

### 2.2 필수 포함 요소
- [ ] **내돈내산/직접구매** 명시 (신뢰도)
- [ ] **장점 3개 이상, 단점 2개 이상** (균형 잡힌 리뷰)
- [ ] **실제 사용 사진 3~5장** (박스, 본체, 사용 모습)
- [ ] **가격 비교** (쿠팡 vs 타 쇼핑몰)
- [ ] **쿠팡 파트너스 링크** (하단에 1~2개 배치)
- [ ] **태그**: 제품명, 브랜드, 카테고리, "내돈내산", "추천"

### 2.3 쿠팡 파트너스 링크 생성 방법
1. 쿠팡 파트너스 로그인 → 상단 메뉴 '링크 생성'
2. 상품 검색 → '링크 만들기' 클릭
3. '짧은 링크' 또는 '일반 링크' 복사
4. 블로그 본문 하단에 `👉 [최저가 확인하기](링크)` 형태로 삽입

### 2.4 작성 예시 (무선청소기)

**제목**: 다이슨 V12 디텍트 슬림 솔직 리뷰 - 3주 사용 후 장단점 총정리

**본문 요약**:
- 도입: 기존 유선청소기 무거워서 무선 찾아봄, 다이슨 vs 삼성 vs LG 비교
- 기본정보: 59만원대, 0.35kg, 60분 사용, 로켓배송
- 장점: ① 가벼워서 한손 조작 가능 ② 먼지 감지 센서 신기함 ③ 배터리 교체형
- 단점: ① 가격 비쌈 ② 먼지통 비우기 번거로움 ③ 헤드 교체 비쌈
- 총평: 가벼운 무선청소기 찾는 분께 추천, 예산 넉넉하면 다이슨
- 링크: `👉 쿠팡에서 최저가 확인하기`

## 3. 글 발행 및 승인 대기

### 3.1 발행 체크리스트
- [ ] 글 3~5개 모두 발행 완료
- [ ] 각 글에 쿠팡 파트너스 링크 1개 이상 포함
- [ ] 네이버 검색 노출 확인 (발행 후 1~2시간 후 검색)
- [ ] 모바일/PC 모두에서 정상 표시 확인

### 3.2 승인 신청
1. 쿠팡 파트너스 로그인 → '내 정보' → '매체 관리'
2. '매체 추가' → 네이버 블로그 URL 입력 (`https://blog.naver.com/내아이디`)
3. 승인 대기 (보통 1~3영업일)

### 3.3 승인 후 확인사항
- [ ] '매체 상태'가 '승인됨'으로 변경
- [ ] API 키 발급 가능해짐 (마이페이지 → API 관리)
- [ ] 수익 리포트 메뉴 활성화

## 4. 자동화 시스템 연동

### 4.1 API 키 발급
1. 쿠팡 파트너스 → 마이페이지 → API 관리
2. 'API 키 발급' 클릭
3. **Access Key**, **Secret Key** 복사 → 안전한 곳에 저장

### 4.2 시스템 설정
```bash
cd blog-auto-poster
cp config/secrets.yaml.example config/secrets.yaml
vim config/secrets.yaml
```

```yaml
# config/secrets.yaml
affiliates:
  coupang:
    apiKey: "여기에_Access_Key_붙여넣기"
    apiSecret: "여기에_Secret_Key_붙여넣기"
    trackingId: "내_트래킹_ID"  # 쿠팡 파트너스에서 확인

platforms:
  naver-blog:
    enabled: true
    blogName: "내_블로그_아이디"
    # 네이버 블로그는 API가 제한적이므로
    # 초기엔 티스토리/워드프레스로 시작 권장
```

> ⚠️ **주의**: 네이버 블로그는 공식 API가 없어 자동 발행이 제한적입니다.
> **초기엔 티스토리/워드프레스/유튜브 쇼츠로 자동화 시작**하고,
> 네이버 블로그는 수동 발행 병행하거나 추후 스크래퍼 방식 고려

### 4.3 추천 자동화 플로우 (티스토리/워드프레스 기준)

```yaml
# config/default.yaml
platforms:
  tistory:
    enabled: true
    blogName: "내_티스토리_블로그명"
    username: "티스토리_아이디"
    password: "티스토리_비밀번호"
    apiKey: "티스토리_API_키"

  wordpress:
    enabled: true
    url: "https://내워드프레스사이트.com"
    username: "워드프레스_관리자"
    appPassword: "앱_비밀번호"
```

## 5. 운영 시작 체크리스트

### 5.1 초기 검증 (자동화 시작 전)
- [ ] `npm run cli -- config` 위자드로 설정 검증
- [ ] `npm run cli -- research "무선청소기" --limit=5` 키워드 리서치 테스트
- [ ] `npm run cli -- generate --template=coupang-product-review --product=상품ID --platform=tistory --dry-run` 템플릿 렌더링 확인
- [ ] `npm run web:dev` 대시보드 접속 확인

### 5.2 자동화 스케줄 시작
```bash
# 스케줄러 활성화 (config/default.yaml에서 enabled: true)
npm run cli -- schedule enable daily-keyword-research
npm run cli -- schedule enable daily-content-generation
npm run cli -- schedule enable daily-publishing
npm run cli -- schedule enable hourly-analytics-sync

# PM2로 백그라운드 실행
pm2 start dist/cli/index.js --name "blog-poster-scheduler" -- schedule
pm2 start dist/web/server/index.js --name "blog-poster-web"
```

### 5.3 모니터링 포인트
| 지표 | 확인 주기 | 기준 |
|------|-----------|------|
| 발행 성공률 | 매일 | 90% 이상 |
| 키워드 리서치 품질 | 주간 | 상위 10개 중 5개 이상 유효 |
| 쿠팡 클릭/전환 | 주간 | CTR 1% 이상, 전환율 0.5% 이상 |
| 에러 로그 | 매일 | 크리티컬 에러 0건 |

## 6. 수익 극대화 팁

### 6.1 키워드 전략
| 유형 | 예시 | 특징 |
|------|------|------|
| **비교 키워드** | "다이슨 V12 vs 삼성 제트" | 구매 직전, 전환율 높음 |
| **추천 키워드** | "가성비 무선청소기 추천" | 검색량 많음, 경쟁 치열 |
| **문제해결 키워드** | "강아지 털 청소기 추천" | 니치, 경쟁 낮음 |
| **시즌 키워드** | "여름 에어컨 추천 2024" | 시기성, 급상승 트렌드 |

### 6.2 템플릿 다변화
- `coupang-product-review` (기본 리뷰)
- `product-comparison` (비교 글)
- `buying-guide` (구매 가이드)
- `seasonal-recommendation` (시즌 추천)

### 6.3 멀티 플랫폼 분산
| 플랫폼 | 용도 | 발행 빈도 |
|--------|------|-----------|
| 티스토리 | 메인 수익 블로그 | 일 2~3개 |
| 워드프레스 | SEO 자산 구축 | 일 1~2개 |
| 유튜브 쇼츠 | 2차 트래픽 유입 | 일 1개 |
| 네이버 블로그 | 브랜딩/신뢰도 | 주 2~3개 (수동) |

## 7. 문제 해결

| 상황 | 대응 |
|------|------|
| **쿠팡 승인 거절** | 글 품질 개선(사진 추가, 상세 후기), 다른 블로그로 재신청 |
| **API 키 오류** | 키 재발급, secrets.yaml 공백/따옴표 확인 |
| **발행 실패** | 대시보드 에러 로그 확인 → 플랫폼별 인증 갱신 |
| **수익 0원 지속** | trackingId 확인, 링크 클릭 테스트, 클릭/전환 분석 |
