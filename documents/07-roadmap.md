### 1.5 인텔리전스 레이어

- [x] **TopicSelector** - 검색 볼륨 × 커미션율 × 콘텐츠 갭 × 트렌드 속도 가중치 스코어링

### 1.6 스케줄러 및 자동화

  - 매일 08:00 - 발행

- [x] CLI 수동 트리거 지원

### 1.7 CLI 및 UI

- [x] **설정 위자드** - 대화형 프롬프트로 `config/secrets.yaml` + `config/local.yaml` 작성

## 즉시 실행 체크리스트 (오늘 할 일)

```bash
# 1. 네이버 블로그 개설 및 3~5개 글 작성
#    - 무선청소기, 로봇청소기, 에어프라이어 등
#    - 장점 3개/단점 2개, 실사용 사진, 쿠팡 링크 필수

# 2. 쿠팡 파트너스 가입 → 매체 승인 신청
#    - 보통 1~3영업일 소요

# 3. 승인 후 즉시 실행
cd blog-auto-poster
cp config/secrets.yaml.example config/secrets.yaml
# → API 키 입력
npm run build
npm run cli -- schedule enable daily-keyword-research
npm run cli -- schedule enable daily-content-generation
npm run cli -- schedule enable daily-publishing
pm2 start dist/cli/index.js --name "blog-poster-scheduler" -- schedule
pm2 start dist/web/server/index.js --name "blog-poster-web"
```
